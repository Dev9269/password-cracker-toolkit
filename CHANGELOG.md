# Changelog

## [1.1.0] - 2026-07-19

### Added
- `--version` flag to display tool version
- `SECURITY.md` with responsible disclosure policy
- `CONTRIBUTING.md` with development guide

## [1.0.0] - 2026-07-18

### Added
- Initial release
- Dictionary, brute force, hybrid, and rule-based attack modes
- Auto mode that tries dictionary, hybrid, then brute force sequentially
- GPU acceleration support via hashcat
- Password strength analysis with feedback
- MD5, SHA1, and SHA256 hash support
- Batch cracking mode with hash file input
- JSON and CSV export for batch results
- Colorized terminal output
- Sample wordlist generation
