# Contributing to Password Cracker Toolkit

Thank you for your interest in contributing! This project is intended for educational and authorized security testing purposes only.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Install dependencies: `pip install -r requirements.txt`
4. Create a branch: `git checkout -b feature/your-feature-name`

## Development

- Python 3.10+ required
- Run tests: `python -m pytest tests/`
- Run linting: `ruff check .`

## Pull Request Guidelines

- Keep changes focused and atomic
- Add tests for new features
- Update documentation as needed
- Ensure all existing tests pass
- Reference any related issues with `Closes #<number>`

## Code Style

- Follow PEP 8 conventions
- Use type hints for all function signatures
- Write docstrings for public functions
- Keep functions small and single-purpose

## Security Notice

This tool is for authorized security testing and education only. Do not submit PRs that enable illegal or unethical use.
